About FFU Studio

FFU Studio wraps the current VE-ES ffugen.py and ffu.py for use with any compatible Otomate FFU template. It includes a private Windows Python runtime and its font libraries.

No game assets or fonts are included. Keep your original template and test each generated font in its target game. A forced cell height can clip glyphs, and an incorrect header height can cause a game crash.
